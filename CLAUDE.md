# RiderSpeak — сайт-визитка преподавателя английского в конной сфере

## О проекте
Одностраничный сайт-визитка на React + Vite.
Владелец: Борисова Дарья, преподаватель английского языка для конников.
Название: RiderSpeak.
Язык контента: русский.
Запуск: `npm run dev -- --host` (просмотр с телефона в локальной сети).
Проверки: `npm run build` и `npx oxlint` должны проходить без ошибок и замечаний.

## Стек
- React (функциональные компоненты, хуки)
- Vite
- Чистый CSS (CSS-переменные для токенов, без Tailwind и UI-библиотек)
- Никаких внешних зависимостей, кроме React/Vite (карусели, поп-ап, анимации — свой код)

## Деплой (GitHub Pages)
- Репозиторий: `github.com/Versipellis99/RiderSpeak` (имя с заглавными R и S).

- `vite.config.js`: `base: '/RiderSpeak/'`. **Регистр важен**: Pages различает его, при несовпадении сайт открывается пустым.

- Коммитить и пушить в `main` — только когда пользователь просит. По умолчанию не коммитить.

## Технические договорённости (CSS и поведение)
- Все стили секций — в `src/styles/sections.css`, токены — `variables.css`, база — `global.css`. Тёмные секции — класс `.section--dark` (в конце sections.css): переопределяет фон, текст, карточки, кнопки, подписи.
- **Порядок правил важен**: мобильные `@media` должны стоять ПОСЛЕ базовых правил того же селектора, иначе базовые их перебивают (из-за этого уже ломался мобильный поп-ап). Мобильные правила поп-апа и `.lessons__intro` лежат в отдельном media-блоке в конце файла.
- **Hover только для мыши**: все `:hover` обёрнуты в `@media (hover: hover)`, чтобы на тач-экранах не было «залипания». Карточки в тёмных секциях: на тач-экранах и до 768px рамка всегда акцентная (`--color-accent-hover`), на ПК — приглушённая, акцентная при наведении.
- Якорные ссылки обрабатывает общий хук `useAnchorScroll` в `App.jsx` (плавный `scrollIntoView`). Заглушки `href="#"` отменяют переход (`preventDefault`) и не открывают новую вкладку.
- Появление секций при скролле: хук `useRevealOnScroll` в `App.jsx` (классы `.reveal` / `.is-visible`), Hero исключён; при `prefers-reduced-motion` отключено.
- Внешние ссылки: `target="_blank" rel="noopener noreferrer"`; `tel:` и `mailto:` — без `target`.
- Доступность: `:focus-visible` (в тёмных блоках светлая обводка), у иконок `aria-label`, у `svg` `aria-hidden`, у фото содержательные `alt`.
- Hero h1: цвет задан вручную владельцем (`#f0c9a8` в `.hero h1`), сейчас без `transition` и анимаций. Мерцание заголовка в Chrome при скролле не удалось победить через CSS; в правиле остались хаки (`will-change`, `translateZ(0)`, `text-rendering`, у `.hero` — `contain: paint`). Считаем это багом браузера, новых хаков без запроса не добавлять.

## Медиа и карусели
- Фото: `src/assets/media/` (Hero: `hero-photo2.webp`, «Обо мне»: `about-1/2/3.webp`), отзывы: `src/assets/reviews/` (`ФотоОтзыв1–4.webp`, `ВидеоОтзыв1–5.mp4`).
- Порядок отзывов определяется номерами в именах файлов (импорты в `Results.jsx`). Для фото всегда указывать `width`/`height` (реальные размеры), `loading="lazy"` (кроме Hero), `decoding="async"`.
- Hero-фото: без `loading="lazy"`, с `fetchPriority="high"`; `hero-photo2.webp` — 1080×1920; на всех экранах обрезается сверху до пропорции 4:5 (`aspect-ratio: 4/5`, `object-position: center bottom`), т. к. верхние ~30% — пустой светлый фон.
- Фото в «Обо мне»: слот `--square` имеет `aspect-ratio: 1/1` с обрезкой; `--tall` сейчас `about-3.webp`, `--square` — `about-1.webp`.
- Общий компонент `Carousel.jsx` (нативный scroll-snap + стрелки): на десктопе 3 слайда, до 900px — 2, до 768px — 1 с краем следующего. Используется для видео-отзывов и фото переписок.
- Видео: `preload="metadata"`, адрес подставляется только когда карусель подходит к экрану (IntersectionObserver), к адресу добавлено `#t=0.001` (первый кадр как постер на iOS). Одновременно играет только одно видео. Свои постеры не нужны.
- Проверять вёрстку в настоящем Chrome (через `puppeteer-core`, установленный ВНЕ проекта, например в scratchpad), а не только по коду.
